# Site Images

This folder is where the site's photography lives. The CSS in `assets/css/styles.css` references these exact filenames as background images, with the original brand-palette gradients as an automatic fallback if a file is missing — so the site never breaks, it just looks a little less finished until each photo is added.

| Filename | Used for | Suggested size |
|---|---|---|
| `hero.jpg` | Homepage hero background | 1920×1080 (landscape) |
| `studio.jpg` | About/Mía Story section main visual | 1000×1250 (portrait) |
| `hands.jpg` | About/Mía Story section inset photo | 900×1125 (portrait) |
| `gallery-before.jpg` | Before/after slider — "before" panel | 1600×1200 (landscape) |
| `gallery-after.jpg` | Before/after slider — "after" panel | 1600×1200 (landscape) |

Drop a JPEG in with the exact filename above and it picks up automatically — no other code changes needed.
